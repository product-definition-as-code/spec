## Fixed release decisions

- The method/serialization pair is **0.3.0 / v1alpha2**. Preserve released v1alpha1; migrate BR-to-UC scope to UC governance explicitly.
- LC local IDs are not graph nodes or anchors. Transition artifact references originate at LC; authored diagnostic occurrences remain separate while impact edges are deduplicated by source/field/target.
- Model impact is one hop under canonical polarity, with pinned unchanged judgments. Only absent Constraint scope is global. An edited candidate starts its own next one-hop computation.
- Apply gates on unresolved model impact, then reports effective downstream citation consequences. Forecast staleness does not veto apply or enter warnings-as-errors.
- Evidence is optional, external and traceable; outcomes and citation status remain separate. No execution, test management, mandatory coverage or evidence apply gate.

## Qualification gates and known remaining evidence

- Schema meta-validation and closed references; old v1alpha1 unchanged; templates on LF and CRLF.
- Migration idempotence, missing/ambiguous/wrong-type targets, preserved broad scope and no inferred associations. Rebase live overlays explicitly; retain archives and consumer pins.
- Fixture schema/diagnostic-path/pin integrity, including new evidence and acknowledgment pins. Negative cases must remain negative.
- Runner unit and integration checks, cross-platform CI, built binary and legacy command compatibility.
- An actual implementation run of lifecycle, one-hop accounting, ordered apply gates, affected citations and any claimed evidence integration. New fixture presence is not proof of implementation support.
- Review/instrumentation proving forecast-before-write and transactional rollback. Outcome authenticity and semantic authoring constraints remain outside deterministic validation.
- Existing unrelated planned cases remain documented in the conformance README; no claim of a complete normative suite is made.

Until the implementation run and release checks exist, the candidate is reviewable implementation work, not a verified release.
