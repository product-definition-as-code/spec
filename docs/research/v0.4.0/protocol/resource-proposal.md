The session ceiling follows 64 authoring plus eight evaluator units, each at most 16,000 tokens: 1,152,000; adding the proposed calibration maximum gives 1,184,000. The rounded aggregate cap is 1,200,000. This is a containment envelope, not an estimate that every unit needs that much or that the pilot is statistically sufficient. Shared context and tool calls still count. Any unmetered additional agent call is not a free extra unit.

Time, memory, query and attention values are deliberately small candidate limits for the initial benchmark, not published feasibility results. A limit can produce incomplete evidence; it never justifies declaring success or dropping failures. Human attention is a measured research cost, not replaced by evaluator-agent token counts. Independent review coverage must be judged sufficient for the claims, even if that means pause/reduction.

## Metering and bounded operation

Before execution, name the operator, authors, independent evaluators and product/formal-methods reviewers. Record actual provider model IDs, tool versions, licence/access status, OS, input/output/cached tokens, billed cost and price revision, reasoning latency, retries, reconstruction time/tokens, redundant work and human minutes/decisions. Record active versus elapsed wall time and raw invocation results. Explain unavailable measurements; if a cost essential to H0 cannot be measured, do not claim a cost advantage.

Stop before exceeding any approved cap. No unattended retries, recursive issue generation, speculative new work or automatic later phase. Access failure can pause one candidate while independent documentary work proceeds; it does not falsify H0. Experimental defects require classification, not silently changed tests. Correctable repairs retain original attempts, require explicit bounded approval and fresh held-out evaluation; they do not automatically abandon the research.

The pilot's top-level counts bound model construction/evaluation, but a backend-specific solver/query count remains pending; this is an entry blocker, not an unlimited allowance. Do not start scored work until every cap and metering field is approved and enforceable.
