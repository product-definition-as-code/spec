# Pilot interface (research only)

All four cohorts produce `decision.py` exposing `decide(x: dict) -> dict` as an executable **product decision model**, not production software or an implementation proof. Input keys: `status` (0 REQUESTED, 1 CONFIRMED, 2 CANCELLED, 3 EXPIRED), `used`, `capacity`, `days`, `due` (bool), `actor`, `owner`, `issuer`, `authenticated` (bool), `editor` (bool), `operation` (0 CONFIRM, 1 CANCEL, 2 EXPIRE, 3 EDIT). Integers are mathematical/nonnegative where stated in intent; inputs include invalid values to test rejection. Output exactly `accepted` (bool), `status`, `used`, `owner`; rejected operations preserve state. No persistent state, imports with side effects, network or input-dependent file access.

Cohorts 3/4 additionally supply ordinary SMT-LIB2 `contract.smt2` in QF_LIA, declaring no free constants/check-sat/exit/reset commands and defining `Step` with signature `(status Int, used Int, capacity Int, days Int, due Bool, actor Int, owner Int, issuer Int, authenticated Bool, editor Bool, operation Int, accepted Bool, nextStatus Int, nextUsed Int, nextOwner Int) -> Bool`. It is a total decision relation including rejected outcomes. Names/ordering are fixed interchange plumbing, not a PDaC formal language/schema. Agents own interpretation, use any ordinary derived predicates, and document assumptions in `report.json`.

`report.json`: status (`ready` or `blocked`), unresolved_decisions (list; must be empty to continue), assumptions (list), semantic_decisions (list), dependencies (mapping property to source paths), evidence (list of objects with property, source_sha256 mapping, outcome, applicability), findings (list), reconstruction_seconds (number or null). Report unknown/unresolved choices rather than silently deciding. PDaC outputs retain released product artifacts and real Product Changes; other cohorts retain equivalent requirements, change logs and history without PDaC. Every episode is a fresh session; predecessor outputs/history are preserved. No reference encoding is given to authors. Common public examples are not held-outs.

Coordinator builds orchestration/public protocol; semantic designer builds public intent/tasks; independent custodian builds private oracle/cases against public intent, with separate review. No scored session before owner G1 decision. Private cases must not be opened by coordinator or author sessions before outputs freeze. Mount isolation excludes custodian and other cohorts; remaining same-host/common-model trust limitations disclosed.
