## Purpose

Builds a tool that reads a product definition and wants to state, credibly, that it behaves as the definition requires.

## Goals

Learn whether the tool satisfies the definition, and be able to show the evidence to someone who did not write the tool.

## Responsibilities

Runs the cases, reads the verdict, and either corrects the tool or contests the case.

## Boundaries

Does not decide what the cases assert. An implementer who could change the expectation to match the tool would be measuring nothing.
