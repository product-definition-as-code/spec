## Purpose

Reads the portable kernel configuration before discovering product artifacts.

## Goals

Locate the same Product Definition as every other conforming implementation.

## Responsibilities

Applies the versioned product root and validation policy.

## Boundaries

Does not interpret another implementation's extension namespace as kernel policy.
