# Signatories

The people below have signed [the Product Definition as Code Manifesto](MANIFESTO.md).

## How to sign

1. Open [this file in GitHub's editor](https://github.com/product-definition-as-code/spec/edit/main/SIGNATORIES.md). GitHub forks the repository for you if you cannot write to it.
2. Add one line to the end of the table below, keeping the numbering: `| n | Your Name | Affiliation (optional) | [yoursite.com](https://yoursite.com) (optional) |`. The link can be a GitHub profile, a site or LinkedIn.
3. Propose the change as a pull request titled `sign: <your name>`.

Signing means you endorse the values and principles of the manifesto. It does not commit you, your employer, or your projects to anything else. Affiliations are listed for identification only.
